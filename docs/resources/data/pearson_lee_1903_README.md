# Dataset: Pearson and Lee (1903) Height data

## Overview
This dataset is a modified version of the `PearsonLee` dataset from the `HistData` R package. It contains the heights (in inches) of parents and their adult children, classified by gender. The original data were reported in frequency tables; a small amount of random noise has been added to the values to break ties and allow individual-level analysis.

## Original Source

- Pearson, K. and Lee, A. (1896). Mathematical contributions to the theory of evolution. On telegony in man, etc. *Proceedings of the Royal Society of London*, *60*, 273-283.

- Pearson, K. and Lee, A. (1903). On the laws of inheritance in man: I. Inheritance of physical characters. *Biometika*, *2*(4), 357-462. (Tables XXII, p. 415; XXV, p. 417; XXVIII, p. 419 and XXXI, p. 421.)
