Items

Selecting the Item ID will take you to a page displaying the question, answer, and (if available) worked solutions and other notes.

Clicking the Stem can be used to quickly preview a question, but may not show all elements (e.g., graphs, mathmatical text, etc.).

The TXT column shows the question and answer in raw text format for easy copying and pasting.

The Export checkbox allows instructors to mark questions for export and generate a consolidated plain-text file for easy copying into an Canvas. Because the export is just raw text, images are not included.

The R Exam column provides the item’s R Markdown code for any instructors using the “exams R package”. This package enables you to do things like:

  • Randomize question order and question elements (e.g., values, names, etc.)
  • Display corresponing graphs, and other diagrams
  • Generate multiple exam versions automatically
  • Export exams to different formats (Canvas, Word documents, Webpages, PDFs, and more)

Note: This approach requires solid knowledge of R and the exams package.
